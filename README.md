# Technical Analysis

A structured journal for tracking stock and crypto chart analysis, trade setups, and market observations.

## Structure

```
technical-analysis/
├── analyses/
│   ├── stocks/       # Stock chart analyses (e.g., AAPL-2026-09.md)
│   └── crypto/       # Crypto chart analyses (e.g., BTC-2026-09.md)
├── setups/           # Active trade setups being monitored
├── watchlist/        # Symbols on the radar with brief notes
└── templates/        # Reusable analysis templates
```

## File Naming Convention

- Analyses: `SYMBOL-YYYY-MM[-description].md`  
  Example: `AAPL-2026-09-breakout.md`, `BTC-2026-09.md`
- Setups: `SYMBOL-YYYY-MM-DD.md`

## Timeframes

| Abbreviation | Meaning     |
|--------------|-------------|
| 1W           | Weekly      |
| 1D           | Daily       |
| 4H           | 4-hour      |
| 1H           | 1-hour      |
| 15m          | 15-minute   |

## Common Indicators Used

- EMA (8, 21, 50, 200)
- RSI (14)
- MACD (12, 26, 9)
- Volume profile / VWAP
- Support / Resistance levels
